# BookVerse Data Sources

## Goals

BookVerse requires a diverse book dataset covering:

- International books
- Indian authors
- Hindi literature
- Manga
- Manhwa
- Multiple languages
- Fiction and non-fiction

## Required Metadata

- Title
- Author
- Description
- Genres
- Language
- Publication year
- Pages
- Rating
- Ratings count
- ISBN
- Publisher
- Cover
- Content type

## Source Evaluation Criteria

Each potential source will be evaluated based on:

1. Coverage
2. Metadata quality
3. API/data availability
4. Licensing and terms of use
5. Rate limits
6. Reliability
7. Duplicate handling
8. Suitability for BookVerse
