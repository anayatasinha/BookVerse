BookVerse
=========

AI-Powered Book Discovery & Recommendation System

BookVerse is an AI-powered platform designed to help readers
discover books based on their interests, reading experience,
mood, genre, popularity, and reading history.

The platform aims to include international books, Indian
literature, Hindi novels, manga, manhwa, and books across
different languages and genres.

Core Features
-------------

- Popular book discovery
- Genre-based recommendations
- Beginner-friendly recommendations
- Personalized recommendations
- Content-based recommendation
- Collaborative filtering
- Semantic book search
- Mood-based discovery
- Natural-language book search
- Reading history and wishlist
- Explainable recommendations
